# Code Review

- Prioritize functional correctness, safety, regressions, and maintainability over purely stylistic violations.
- Report applicable guideline violations from AGENTS.md within the requested review scope, but distinguish them from functional defects.
- Do not modify code during a review unless fixes are explicitly requested.
- Do not compile or run tests; state that nothing was compiled or tested.
